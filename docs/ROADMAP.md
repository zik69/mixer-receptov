# Миксер рецептов — Роадмап

> **Коротко:** Страница «Миксер рецептов». Жмёшь «Мешать» → получаешь
> **2 завтрака + 2 обеда + 2 ужина** на день и список покупок для Ленты.
> Рассчитано на 2 человек. Сделано под телефон — открываешь в магазине.

## Решения, принятые для проекта

| Вопрос | Решение |
|---|---|
| Сколько рецептов на день | 2 завтрака + 2 обеда + 2 ужина (6 карточек) |
| На сколько человек готовим | На 2 |
| Главный сценарий | Телефон, в магазине → интерфейс сразу мобильный |
| Размер каталога сейчас | 30 рецептов, потом расширяем |
| Инфраструктура | Ни сервера, ни аккаунтов. Один сайт-файл, работает без сети |

## P0 — База (минимум, чтобы пользоваться)

### Task-002 — Каталог рецептов (данные) ✅
- **Я как** пользователь **хочу** видеть простые рецепты с ингредиентами и временем готовки, **чтобы** быстро выбрать, что приготовить.
- **Я как** разработчик **хочу** иметь единый файл с рецептами в понятном формате, **чтобы** легко добавлять и менять рецепты.

### Task-004 — Генерация меню на день (2+2+2) ✅
- **Я как** пользователь **хочу** нажать «Мешать» и получить 2 завтрака, 2 обеда и 2 ужина, **чтобы** не думать, что готовить.
- **Я как** пользователь **хочу** чтобы вчерашние рецепты не выпадали снова, **чтобы** не было однообразия.

### Task-005 — Список покупок ✅
- **Я как** пользователь **хочу** видеть итоговый список покупок по выбранным рецептам с правильным количеством, **чтобы** купить всё и не переплатить.
- **Я как** пользователь **хочу** отмечать купленные пункты, **чтобы** не забыть и не купить лишнего.

### Task-006 — Сохранение в браузере ✅
- **Я как** пользователь **хочу** чтобы рецепты на сегодня не менялись при перезагрузке страницы, **чтобы** спокойно идти в магазин по одному списку.
- **Я как** пользователь **хочу** чтобы мои отметки и любимое не пропадали, **чтобы** не настраивать заново каждый день.
