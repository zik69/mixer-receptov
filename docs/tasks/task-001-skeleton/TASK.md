# Task-001 — Каркас + стили + карточка рецепта

## Задача

Нужно сделать основу страницы: разметку, стили и карточку рецепта.
Интерфейс сразу мобильный — главный сценарий «открыл в магазине с телефона».

## Что входит в работу

### 1. `index.html`
Структура страницы:
- Шапка: название «Миксер рецептов»
- Панель управления: кнопка «Мешать» + подпись «2 завтрака · 2 обеда · 2 ужина»
- Секция меню: заголовки «Завтраки», «Обеды», «Ужины» и по 2 карточки в каждой
- Секция «Список покупок»: заголовок, кнопка «Очистить отметки», пустой список
- Подвал

### 2. `styles.css`
Настоящие стили, не заглушка:
- Мобильный-first: сначала стили для телефона, потом `@media (min-width: 720px)` для широкого экрана
- Цвета, отступы, шрифты — через CSS-переменные в `:root` (чтобы потом легко добавить тёмную тему)
- Понятная сетка: на телефоне карточки в одну колонку, на широком экране — в 2-3
- Стили для: шапки, кнопки «Мешать», заголовков секций, карточки рецепта,
  списка ингредиентов, раскрывающихся шагов, чекбоксов, списка покупок, подвала
- Приятная палитра: тёплые тона, скруглённые углы, мягкие тени
- Текст должен читаться без зума на телефоне (минимальный размер 16px для основного текста)

### 3. `app.js`
- Массив из 6 демо-рецептов прямо в файле (по 2 на каждую категорию, чтобы секции были видны сразу)
- Функция отрисовки карточек в нужную секцию
- Кнопка «Мешать» пока переставляет демо-рецепты местами (без случайного выбора из каталога — это Task-004)
- Галочка «Добавлю в покупки» уже собирает плоский список ингредиентов (сведение и группировка — Task-005)

### 4. Карточка рецепта
Должна содержать:
- Категория («Завтрак» / «Обед» / «Ужин»), время готовки, количество порций
- Название
- Список ингредиентов с количеством
- Раскрывающийся блок «Как готовить» с шагами (по кнопке «Показать рецепт»)
- Чекбокс «Добавлю в покупки»

## Как понять, что готово

- [ ] Страница открывается с телефона, всё читается без зума
- [ ] Видны 3 секции: завтраки, обеды, ужины — по 2 карточки в каждой
- [ ] Карточка показывает категорию, время, порции, ингредиенты
- [ ] Кнопка «Показать рецепт» раскрывает шаги
- [ ] Чекбокс «Добавлю в покупки» кликается
- [ ] Кнопка «Мешать» переставляет карточки
- [ ] Секция «Список покупок» видна и готова принимать пункты
- [ ] На широком экране карточки выстраиваются в 2-3 колонки
- [ ] В консоли браузера нет ошибок

## Что НЕ входит

- Реальный каталог рецептов (Task-002)
- Случайный выбор из каталога (Task-004)
- Список покупок (Task-005)
- Сохранение (Task-006)
- Тёмная тема и анимации (Task-015) — но переменные под них уже заложить
