# Промпт для Task-001

Сделай основу веб-приложения «Миксер рецептов»: разметку, стили и карточку рецепта.
Интерфейс делаем **сразу под телефон** — главный сценарий: пользователь открывает страницу в магазине.

## Файлы

1. `index.html`
2. `styles.css`
3. `app.js`

## Главное правило по стилям

Пиши **мобильный-first**: сначала базовые стили для экрана 360-420px, потом
добавляй `@media (min-width: 720px)` для широкого экрана. На телефоне карточки
в одну колонку, на широком — в 2-3 колонки.

Все цвета, отступы и радиусы вынеси в CSS-переменные в `:root` — потом легко
добавить тёмную тему.

Палитра: тёплая и «вкусная» — кремовый фон, тёплый оранжевый/янтарный акцент,
скруглённые углы (10-16px), мягкие тени. Основной текст не меньше 16px.

## Структура `app.js`

- Массив `DEMO_RECIPES` — 4 демо-рецепта в формате:

```js
{
  id: 1,
  title: "Омлет с сыром и помидорами",
  category: "завтрак",     // завтрак | обед | ужин
  time: 20,
  servings: 2,
  ingredients: [
    { name: "Яйца", amount: "4", unit: "шт" },
    { name: "Сыр", amount: "100", unit: "г" },
    { name: "Помидоры", amount: "2", unit: "шт" }
  ],
  steps: [
    "Взбейте яйца с солью.",
    "Влейте на сковороду и поджарьте полминуты.",
    "Добавьте нарезанные помидоры и сыр, сверните омлет."
  ]
}
```

- Функция `renderCard(recipe)` — собирает карточку и возвращает HTML-элемент
- Функция `renderAll()` — раскладывает демо-рецепты по секциям (по 2 в каждую)
- Обработчик кнопки «Мешать» — перемешивает порядок карточек по секциям
- Чекбокс «Добавлю в покупки» — при клике просто отмечается (список покупок наполняется в Task-005)

## Как должна выглядеть карточка

```
┌─────────────────────────────┐
│ Завтрак · 20 мин · 2 порции │
│ Омлет с сыром и помидорами  │
│ ─────────────────────────── │
│ Ингредиенты                 │
│  • Яйца — 4 шт              │
│  • Сыр — 100 г              │
│  • Помидоры — 2 шт          │
│                             │
│ [ Показать рецепт ]         │
│ [ ] Добавлю в покупки       │
└─────────────────────────────┘
```

Кнопка «Показать рецепт» раскрывает список шагов прямо в карточке (и прячет обратно).
