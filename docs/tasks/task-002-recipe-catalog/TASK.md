# Task-002 — Каталог рецептов (данные)

## Задача

Нужно создать файл с базой рецептов — массив объектов в `recipes.js`.

## Что входит в работу

1. Создать файл `recipes.js` с массивом `RECIPES` из 15-20 несложных рецептов.
2. Каждый рецепт содержит:
   - `id` — число
   - `title` — название
   - `category` — категория: завтрак / обед / ужин / перекус
   - `time` — время готовки в минутах (20-30)
   - `servings` — количество порций
   - `ingredients` — массив объектов `{ name, amount, unit }`
   - `steps` — массив строк (3-5 шагов)
3. Проверить, что ингредиенты простые — продаются в Ленте.
4. Никаких дорогих/редких продуктов (трюфели, мраморная говядина, креветки и т.п.).

## Как понять, что готово

- [ ] Файл `recipes.js` содержит валидный JS-массив
- [ ] В массиве не менее 15 рецептов
- [ ] Каждый рецепт имеет все обязательные поля
- [ ] Время готовки каждого рецепта — от 20 до 30 минут
- [ ] При открытии консоли браузера с подключённым `recipes.js` — массив доступен в консоли

## Что НЕ входит

- HTML-каркас (это Task-001)
- Логика рандомной генерации
- Список покупок
- Интеграция с API Ленты
- Дизайн карточек

## Формат одного рецепта

```js
{
  id: 1,
  title: "Макароны с курицей и овощами",
  category: "ужин",        // завтрак | обед | ужин | перекус
  time: 25,                 // минут
  servings: 2,              // порции
  ingredients: [
    { name: "Макароны", amount: "200", unit: "г" },
    { name: "Куриное филе", amount: "250", unit: "г" },
    { name: "Помидор", amount: "2", unit: "шт" },
    { name: "Лук репчатый", amount: "1", unit: "шт" },
    { name: "Чеснок", amount: "2", unit: "зубчика" },
    { name: "Масло растительное", amount: "2", unit: "ст.л." },
    { name: "Соль", amount: "по вкусу", unit: "" },
    { name: "Перец", amount: "по вкусу", unit: "" }
  ],
  steps: [
    "Отварите макароны по инструкции на упаковке, слейте воду.",
    "Нарежьте куриное филе мелкими кусочками и обжарьте на сковороде до золотистой корочки.",
    "Добавьте нарезанные лук и помидоры, тушите 5 минут.",
    "Выложите макароны к курице с овощами, перемешайте, прогрейте 2 минуты.",
    "Подавайте горячими, посыпав свежей зеленью при желании."
  ]
}
```
