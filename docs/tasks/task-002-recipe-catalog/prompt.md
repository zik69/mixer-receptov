# Промпт для Task-002

Создай для веб-приложения "Миксер рецептов" каталог рецептов.

## Что сделать

Файл `recipes.js` — массив объектов `RECIPES` из 15-20 рецептов.

## Требования к рецептам

- От 15 до 20 рецептов
- Время готовки: 20-30 минут (строго!)
- Ингредиенты: только те, что есть в обычном супермаркете (Лента)
- Никаких дорогих и редких продуктов
- Категории: завтрак, обед, ужин, перекус
- Желательно разнообразие категорий

## Формат

```js
const RECIPES = [
  {
    id: 1,
    title: "Название",
    category: "ужин",
    time: 25,
    servings: 2,
    ingredients: [
      { name: "Продукт", amount: "200", unit: "г" }
    ],
    steps: ["Шаг 1", "Шаг 2"]
  }
  // ... ещё рецепты
];
```

## Примеры рецептов для вдохновения

- Омлет с сыром и помидорами
- Макароны с курицей и овощами
- Гречка с говядиной
- Салат из свежих овощей
- Блинчики с творогом
- Куриные наггетсы домашние
- Рис с овощами
- Картофельное пюре с котлетой
- Яичница с беконом
- Сырники из творога
- Борщ быстрый (на готовой фасоли)
- Пицца на тонком тесте
- Курица в духовке с картошкой
- Суп с макаронами и курицей
- Тосты с авокадо и яйцом
- Тушёная капуста с мясом
- Пельмени домашние (готовые + соус)
