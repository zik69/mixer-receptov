# Task-003 — Словарь ингредиентов

## Задача

Нужно создать справочник ингредиентов, чтобы список покупок собирался правильно:
один и тот же продукт из разных рецептов складывался в один пункт, а количества
складывались в правильных единицах.

## Что входит в работу

### 1. `ingredients.json`

```json
{
  "version": 1,
  "units": {
    "шт":   { "base": "шт",    "factor": 1 },
    "г":    { "base": "г",     "factor": 1 },
    "кг":   { "base": "г",     "factor": 1000 },
    "мл":   { "base": "мл",    "factor": 1 },
    "л":    { "base": "мл",    "factor": 1000 },
    "ст.л.":{ "base": "мл",    "factor": 15 },
    "ч.л.": { "base": "мл",    "factor": 5 },
    "зубчик": { "base": "зубчик", "factor": 1 },
    "пучок": { "base": "пучок", "factor": 1 },
    "банка": { "base": "банка", "factor": 1 },
    "пачка": { "base": "пачка", "factor": 1 }
  },
  "ingredients": [
    {
      "id": "onion",
      "name": "Лук репчатый",
      "aliases": ["лук", "луковица", "репчатый лук", "лук репчатый"],
      "category": "овощи",
      "pantry": false,
      "gramsPerUnit": 100,
      "lentaQuery": "Лук репчатый",
      "pack": null
    },
    {
      "id": "eggs",
      "name": "Яйца куриные",
      "aliases": ["яйцо", "яйца", "яйцо куриное"],
      "category": "молочное и яйца",
      "pantry": false,
      "gramsPerUnit": 55,
      "lentaQuery": "Яйца куриные",
      "pack": { "unit": "десяток", "size": 10 }
    }
  ]
}
```

**Что означают поля:**

| Поле | Что это |
|---|---|
| `id` | Короткий английский код без пробелов. Ключ, по которому ищем |
| `name` | Правильное название для показа пользователю |
| `aliases` | Все варианты написания, которые могут встретиться в рецептах |
| `category` | Группа для группировки в списке покупок |
| `pantry` | `true` — то, что почти всегда есть дома (соль, перец, масло, вода, специи) |
| `gramsPerUnit` | Сколько грамм в одной штуке. Нужно, чтобы «2 шт лука» сложилось с «150 г лука» |
| `lentaQuery` | Как искать этот продукт в Ленте |
| `pack` | Как продаётся: `{ "unit": "десяток", "size": 10 }`. `null` — продаётся поштучно/в развес |

### 2. Состав справочника
- От 60 до 90 ингредиентов
- Покрыть всё, что встречается в обычных рецептах: овощи, фрукты, мясо, птица,
  рыба, крупы, макароны, хлеб, молочное, яйца, масло, специи, консервы, фрукты
- Обязательно покрыть **все** ингредиенты из каталога Task-002

### 3. Файл `unit-test.html` (проверочный)
Страница, которая берёт `ingredients.json`, подставляет 5-6 пар примеров из разных
рецептов и показывает, что получилось после сложения. Проверяем руками в браузере.

## Правила сложения (это потом использует Task-005)

1. Находим ингредиент по `id`, а если его нет — по `aliases`.
2. Переводим количество в базовую единицу: `г` для сыпучих и жидких, `шт` для штучных.
3. Складываем.
4. Обратно в «человеческие» единицы:
   - меньше 1000 г → «X г», иначе → «X кг» (округляем круглым до 10)
   - меньше 1000 мл → «X мл», иначе → «X л» (округляем круглым до 10)
   - штучные → «X шт»
5. Если единицы несводимы («пучок» и «шт») — два подпункта под одним названием.
6. `pantry: true` — в отдельный блок «Уже есть дома» или вообще не показывать.

## Как понять, что готово

- [x] `ingredients.json` — валидный JSON, открывается без ошибок
- [x] В нём от 60 до 90 ингредиентов (ровно 90) и таблица единиц (15 единиц)
- [x] У каждого ингредиента есть `id`, `name`, `aliases`, `category`, `pantry`
- [x] `aliases` покрывают все варианты написания из каталога рецептов (автопроверка: 65 из 65 имён из `recipes.js` находятся по имени или синониму)
- [x] `pantry: true` стоит у соли, перца, масла, воды, специй (22 шт)
- [x] `unit-test.html` показывает правильное сложение в примерах
- [x] Для «Яйца — 2 шт» и «Яйца — 300 г» получается один пункт в штуках: 300 г ≈ 5 шт (по 55 г) + 2 шт ≈ **7 шт**. Примечание: в примере задания было «5-6 шт» — это перевод только граммовой части; после сложения со «2 шт» итог честный 7 шт.
