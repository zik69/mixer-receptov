# Промпт для Task-003

Создай справочник ингредиентов для приложения «Миксер рецептов».

Зачем: рецепты пишут ингредиенты обычными словами — «Лук», «Лук репчатый»,
«2% молоко», «Молоко». Чтобы в списке покупок получился один пункт
«Лук репчатый — 3 шт», нужен общий справочник: код, правильное название,
все варианты написания и единицы измерения.

## Файлы

1. `ingredients.json` — справочник
2. `unit-test.html` — страница для ручной проверки сложения

## Структура `ingredients.json`

```json
{
  "version": 1,
  "units": {
    "шт":    { "base": "шт",     "factor": 1 },
    "г":     { "base": "г",      "factor": 1 },
    "кг":    { "base": "г",      "factor": 1000 },
    "мл":    { "base": "мл",     "factor": 1 },
    "л":     { "base": "мл",     "factor": 1000 },
    "ст.л.": { "base": "мл",     "factor": 15 },
    "ч.л.":  { "base": "мл",     "factor": 5 },
    "зубчик": { "base": "зубчик", "factor": 1 },
    "пучок":  { "base": "пучок",  "factor": 1 },
    "банка":  { "base": "банка",  "factor": 1 },
    "пачка":  { "base": "пачка",  "factor": 1 }
  },
  "ingredients": [
    {
      "id": "onion",
      "name": "Лук репчатый",
      "aliases": ["лук", "луковица", "репчатый лук", "лук репчатый"],
      "category": "овощи",
      "pantry": false,
      "gramsPerUnit": 100,
      "lentaQuery": "Лук репчатый",
      "pack": null
    }
  ]
}
```

### Что означают поля

- `id` — короткий английский код без пробелов, ключ для поиска
- `name` — как показываем пользователю
- `aliases` — все варианты написания, которые встретятся в рецептах.
  **Обязательно включи единственное и множественное число:** «Помидор» и «Помидоры»,
  «Перец» и «Перец чёрный молотый», «Сыр» и «Сыр твёрдый».
  Сейчас в каталоге рецептов встречаются: Яйца, Молоко, Сыр, Помидор, Масло сливочное,
  Соль, Перец, Творог, Сахар, Мука, Масло растительное, Картофель, Лук репчатый,
  Морковь, Чеснок, Куриное филе, Говядина, Фарш, Рис, Гречка, Макароны, Сметана,
  Йогурт, Хлеб, Колбаса, Сосиски, Капуста, Кабачок, Баклажан, Перец болгарский,
  Зелень, Лавровый лист, Вода, Растительное масло — выпиши полный список из
  `recipes.js` и покрой его синонимами.
- `category` — группа: овощи, фрукты, мясо и птица, рыба, крупы и макароны,
  хлеб, молочное и яйца, масло и специи, консервы и полуфабрикаты
- `pantry` — `true` для того, что почти всегда есть дома: соль, перец,
  масло растительное, масло оливковое, вода, сахар, лавровый лист, паприка,
  корица, ванильный сахар, сушеный чеснок, перец чёрный молотый
- `gramsPerUnit` — сколько грамм в одной штуке (лук 100, яйцо 55, картофель 120,
  морковь 80, помидор 120, луковица чеснока 5). Для взвешиваемых — 0
- `lentaQuery` — как искать этот продукт в магазине «Лента»
- `pack` — как продаётся: `{ "unit": "десяток", "size": 10 }` для яиц,
  `{ "unit": "бутылка", "size": 1000 }` для молока,
  `{ "unit": "упаковка", "size": 200 }` для сыра. Если продаётся поштучно или
  вразвес — `null`

## Как считать `gramsPerUnit`

Это нужно, чтобы складывать штуки и граммы одного продукта между собой.
Примерные значения:

| Продукт | Грамм в штуке |
|---|---|
| Лук репчатый | 100 |
| Морковь | 80 |
| Картофель | 120 |
| Помидор | 120 |
| Огурец | 100 |
| Чеснок (зубчик) | 5 |
| Яйцо | 55 |
| Лимон | 100 |
| Перец болгарский | 150 |
| Кабачок | 400 |
| Баклажан | 300 |

## `unit-test.html`

Страница, которая:
1. Подгружает `ingredients.json` через `fetch`
2. Имеет функцию `merge(ingredientsArray)` — складывает по правилам ниже
3. Показывает 5-6 примеров: результат до и после

### Правила сложения

1. Находим ингредиент по `id`, а если нет — по `aliases` (регистронезависимо)
2. Переводим количество в базовую единицу: `г` для сыпучих, `мл` для жидких,
   `шт` для штучных
3. Складываем
4. Обратно в человеческие единицы:
   - меньше 1000 г → «X г», иначе «X кг» (округлить до 10)
   - меньше 1000 мл → «X мл», иначе «X л» (округлить до 10)
   - штучные → «X шт»
5. Несводимые единицы («пучок» и «шт») → два подпункта под одним названием
6. `pantry: true` → отдельный блок «Уже есть дома»

### Примеры для проверки

- Яйца: «2 шт» + «300 г» → «6 шт» (300/55 ≈ 5.5, округляем)
- Лук: «1 шт» + «1 шт» + «2 шт» → «4 шт»
- Молоко: «200 мл» + «1 л» → «1.2 л»
- Мука: «200 г» + «0.5 кг» → «700 г»
- Масло растительное (pantry) → в блок «Уже есть дома»

- Все примеры должны посчитаться правильно
- В консоли нет ошибок
