# Task-004 — Генерация меню на день (2+2+2)

## Задача

Нужно, чтобы кнопка «Мешать» выдавала 2 завтрака, 2 обеда и 2 ужина —
всего 6 карточек, и чтобы рецепты не повторялись день за днём.

## Что входит в работу

### Правила набора
1. Из каждой категории (`завтрак`, `обед`, `ужин`) берём **ровно 2** рецепта.
2. Рецепт не должен повторяться в последние **3 дня**.
3. Если в категории не хватает рецептов — берём меньше и это видно по подсказке.
4. Понравившиеся (любимые) рецепты выпадают чаще. Если любимых нет — выбираем случайно.
5. Исключённые продукты (см. Task-009) полностью убирают рецепт из выбора.

### Как считать «последние 3 дня»
Вести историю: какие рецепты показывали за последние дни. Хранится рядом с
текущим набором (см. Task-006). При выборе рецепт, который был в истории,
получает вес 0 — он не выпадает, пока есть альтернативы.

### Что происходит при нажатии «Мешать»
1. Пересобрать набор по правилам.
2. Показать новые 6 карточек.
3. Обновить историю: сегодняшние рецепты добавить в начало, старые подрезать.
4. Сохранить (Task-006).

### Первый запуск в новый день
Если на сегодня набора ещё нет — сгенерировать автоматически при открытии страницы.
Если набор есть — показать его, не меняя.

### Подсказка под кнопкой
Под кнопкой «Мешать» показывать, что попало в набор:
`2 завтрака · 2 обеда · 2 ужина` и отдельно — предупреждение, если какой-то
рецепт повторился из-за нехватки выбора.

## Как понять, что готово

- [x] Нажатие «Мешать» даёт ровно 2 карточки в каждой из трёх секций (2, 3 или 4 — по выбору)
- [x] Все 6 рецептов разные
- [x] При 5 нажатиях подряд рецепты почти не повторяются внутри одного набора (исключается текущий набор)
- [x] Рецепт, показанный сегодня, не появляется снова на следующий день (через историю)
- [x] При перезагрузке страницы набор остаётся тем же
- [x] В новый день (смена даты) набор обновляется сам
- [x] Можно выбрать число рецептов на день (2 или 3 в каждой категории)
