# Промпт для Task-004

Сделай генерацию меню на день для приложения «Миксер рецептов».

## Что нужно

По нажатию кнопки «Мешать» собирать набор из **6 рецептов**:
- 2 завтрака (`category: "завтрак"`)
- 2 обеда (`category: "обед"`)
- 2 ужина (`category: "ужин"`)

## Файлы

Работай в существующих файлах:
- `recipes.js` — источник рецептов (уже создан, не менять формат)
- `app.js` — логика
- `index.html` — кнопка `#mix-btn` уже есть

## Правила выбора

1. Из каждой категории берём ровно 2 рецепта.
2. Рецепты внутри набора не повторяются.
3. **Не повторять рецепты из последних 3 дней.** Для этого веди массив `history` —
   список id рецептов по дням, новые сверху, хранить максимум 7 дней.
   Рецепт из истории получает вес 0, если есть альтернативы.
4. Любимые рецепты (пока массив `favorites` пустой — выбирай случайно) выпадают чаще.
5. Исключённые продукты (пока массив `excluded` пустой) полностью убирают рецепт.

## Как выбирать

Взвешенный случайный выбор:
- вес обычного рецепта = 1
- вес любимого = 3
- вес рецепта из истории = 0
- вес рецепта с исключённым продуктом = 0

Выбирать взвешенно, пока в категории не набрано 2 рецепта.

## Состояние

```js
const state = {
  today: null,          // 'YYYY-MM-DD'
  current: [],          // id рецептов, выбранных на сегодня
  history: [],          // [{ date: 'YYYY-MM-DD', ids: [1,4,7] }]
  favorites: [],        // id рецептов
  excluded: [],         // id ингредиентов
  perCategory: 2        // сколько рецептов в каждой категории (2 или 3)
};
```

## Поведение

- **Кнопка «Мешать»** — собрать новый набор, перерисовать карточки, обновить историю.
- **Первый запуск в новый день** — если `state.today` не равен сегодняшней дате,
  собрать набор автоматически при открытии страницы.
- **Перезагрузка страницы** — набор не должен меняться (сейчас сохраняем в памяти,
  постоянное хранение — Task-006, но проверь, что структура `state` подходит для этого).

## Подсказка под кнопкой

Под кнопкой показывай состав набора: `2 завтрака · 2 обеда · 2 ужина`.
Если какой-то рецепт пришлось взять повторно (не хватило выбора) — добавить
строку-предупреждение: «Мало рецептов: [название] повторилось».

## Демо-рецепты

Демо-рецепты из Task-001 сейчас имеют `category: "завтрак" | "обед" | "ужин"`.
Если их не хватает для проверки правил — добавь в `app.js` ещё 2-3 демо-рецепта
в недостающие категории, но не трогай `recipes.js`.

- Нажать «Мешать» — в каждой секции по 2 карточки
- Нажать 5 раз подряд — внутри набора рецепты не повторяются
- Нажать 5 раз подряд — между наборами повторов почти нет (кроме ситуации с историей)
- В консоли нет ошибок
