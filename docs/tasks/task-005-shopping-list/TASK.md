# Task-005 — Список покупок

## Задача

Нужно собрать из отмеченных рецептов один понятный список покупок:
продукты сложены, количества сложены в правильных единицах, есть галочки
«куплено» и понятно, сколько пакетов брать в магазине.

## Что входит в работу

### Откуда берём
Источник — рецепты, у которых отмечен чекбокс «Добавлю в покупки».
Снял отметку — рецепт выпал из списка.

### Как считаем количество
Рецепты рассчитаны на 2 человек (наше число). Если в рецепте указано
`servings: 4`, а мы готовим на 2 — делим количества на 2.

### Как складываем
По правилам Task-003:
1. Находим ингредиент по `id` или `aliases` из `ingredients.json`
2. Переводим в базовую единицу, складываем
3. Возвращаем в человеческий вид: «X г» / «X кг» / «X мл» / «X л» / «X шт»

### Как показываем
- Группируем по `category` из справочника: Овощи, Мясо и птица, Молочное и яйца...
- Внутри группы — по алфавиту
- Продукты с `pantry: true` — в отдельный блок **«Уже есть дома»** (сверху, мелким шрифтом)
- Если количество не сходится (напр. «по вкусу», «1-2 шт») — показать как есть,
  без сложения, отдельной строкой
- Если ингредиент не найден в справочнике — показать как есть и **подсветить**,
  чтобы было видно, что справочник надо дополнить

### Сколько брать в магазине
Если у ингредиента в справочнике есть `pack`, показывать вторым мелким текстом:
- Яйца — 6 шт → `1 десяток`
- Молоко — 1.2 л → `2 бутылки по 1 л`
- Сыр — 300 г → `2 упаковки по 200 г`
Округлять вверх.

### Галочки и кнопки
- У каждого пункта — чекбокс «куплено». Купленное — перечёркнуто и приглушено
- Кнопка «Снять отметки» — снимает все галочки купленного
- Отметки должны переживать перезагрузку (Task-006)

### Порядок в списке
Непокупленное — сверху, купленное — внизу. Чтобы не терять из виду.

## Как понять, что готово

- [x] Отметка «Добавлю в покупки» на карточке добавляет ингредиенты в список
- [x] Два рецепта с луком дают один пункт «Лук репчатый — X г», а не два пункта
- [x] Молоко в граммах и литрах складывается правильно
- [x] Есть блок «Уже есть дома» с солью, перцем и маслом
- [x] Количество пересчитано под 2 человек (масштабирование по `servings`)
- [x] У яиц, молока и сыра показано, сколько пакетов брать
- [x] Галочка «куплено» перечёркивает пункт и переносит его вниз
- [x] После перезагрузки страницы отметки сохраняются (через Task-006)
- [ ] Незакрытые продукты подсвечены — в справочнике есть все продукты из каталога, поэтому подсветка не срабатывает в норме; код готов
