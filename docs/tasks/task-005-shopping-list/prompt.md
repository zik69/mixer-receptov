# Промпт для Task-005

Сделай список покупок для приложения «Миксер рецептов».

## Что нужно

Когда у рецепта отмечен чекбокс «Добавлю в покупки», его ингредиенты
попадают в один общий список. Одинаковые продукты из разных рецептов
складываются в один пункт с общим количеством.

## Файлы

Работай в существующих файлах:
- `app.js` — логика
- `index.html` — секция `.shopping`, список `#shopping-list`, кнопка `#clear-btn`
- `styles.css` — стили списка
- `ingredients.json` — справочник (создаётся в Task-003)
- `recipes.js` — рецепты

## Как считать количество

- Готовим на **2 человек**
- В рецепте `servings: 2` → коэффициент 1
- В рецепте `servings: 4` → коэффициент 0.5 (делим все количества)
- В рецепте `servings: 1` → коэффициент 2

## Как складывать

Используй `ingredients.json`:

1. Найди ингредиент по `id`, а если нет — по `aliases` (регистронезависимо)
2. Переведи количество в базовую единицу через таблицу `units`
3. Сложи с тем же ингредиентом из других рецептов
4. Верни в человеческий вид:
   - меньше 1000 г → «X г», иначе «X кг» (округлить до 10)
   - меньше 1000 мл → «X мл», иначе «X л» (округлить до 10)
   - штучные → «X шт»
5. Несводимые единицы («пучок» и «шт») → два подпункта под одним названием

## Что показывать

```
Овощи
  □ Лук репчатый — 3 шт
  □ Морковь — 400 г
  □ Помидоры — 4 шт

Молочное и яйца
  □ Молоко — 1.2 л        2 бутылки по 1 л
  □ Сыр твёрдый — 300 г   2 упаковки по 200 г
  □ Яйца куриные — 6 шт   1 десяток

Уже есть дома
  Соль, перец чёрный молотый, масло растительное
```

- Группы — по `category` из справочника, внутри группы по алфавиту
- Второй мелкий текст справа — сколько пакетов брать, если у ингредиента есть `pack`
  (округлять вверх). Если `pack` нет — ничего не писать
- `pantry: true` → в блок «Уже есть дома», без галочки
- Количество не число («по вкусу», «1-2») → показать как есть, без сложения
- Ингредиент не найден в справочнике → показать как есть и **подсветить цветом**,
  чтобы было видно, какой продукт надо добавить в справочник

## Галочки и кнопки

- У каждого пункта — галочка «куплено»
- Купленное: текст перечёркнут, пункт приглушён, **уезжает вниз списка**
- Кнопка «Снять отметки» — снимает все галочки купленного
- Отметки должны сохраняться (пока в памяти; постоянное хранение — Task-006)

## Обновление списка

Список пересобирается, когда:
- отметка «Добавлю в покупки» изменилась
- набор рецептов изменился (Task-004)
- галочка «куплено» изменилась (только перестановка, не пересборка)

## Проверка

- Отметить 2 рецепта с луком → один пункт «Лук репчатый — 3 шт»
- Отметить рецепт с 4 порциями → количества вдвое меньше
- Галочка «куплено» → перечёркивает и переносит вниз
- Кнопка «Снять отметки» → всё снова активное
- В консоли нет ошибок
