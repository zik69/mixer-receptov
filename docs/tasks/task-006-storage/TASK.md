# Task-006 — Сохранение в браузере

## Задача

Нужно, чтобы приложение помнило состояние между запусками: набор рецептов на
сегодня, отметки в списке покупок, любимое, исключённые продукты.

Без этого приложением нельзя пользоваться каждый день: рецепты будут
меняться при каждой перезагрузке, и один раз сходить в магазин не получится.

## Что входит в работу

### Что сохраняем
| Поле | Что это |
|---|---|
| `version` | Версия формата. При изменении формата — поднять на 1 |
| `today` | Дата набора: `YYYY-MM-DD` |
| `current` | id рецептов, выбранных на сегодня |
| `history` | За последние 7 дней: `[{ date, ids: [...] }]` |
| `favorites` | id любимых рецептов |
| `excluded` | id исключённых ингредиентов |
| `perCategory` | Сколько рецептов в каждой категории (2 или 3) |
| `checkedItems` | id купленных продуктов в списке покупок |
| `shoppingEnabled` | id рецептов, отмеченных «Добавлю в покупки» |

### Как сохраняем
- Хранилище — `localStorage` браузера (данные остаются на устройстве, ничего никуда не уходит)
- Один ключ: `mixer-state-v1`
- Пишем при каждом изменении, но не чаще раза в секунду
- При открытии страницы: читаем, восстанавливаем

### Если данных нет или они старые
- Данных нет → пустое состояние, приложение работает как в первый раз
- Формат другой версии → начинаем с чистого состояния, старые данные не ломают работу
- Данные есть, но `today` не совпадает с сегодняшней датой → набор обновится
  автоматически, а покупки и любимое останутся

### Кнопка сброса
В подвале — ссылка «Сбросить всё». Спрашивает подтверждение и очищает хранилище.
Это страховка, чтобы пользователь мог начать с чистого листа.

## Как понять, что готово

- [ ] Выбрал рецепты, нажал «Мешать», перезагрузил страницу — набор тот же
- [ ] Отметки «куплено» в списке покупок пережили перезагрузку
- [ ] Следующий день — набор обновился сам, а покупки и любимое остались
- [ ] Кнопка «Сбросить всё» очищает всё и приложение начинает с нуля
- [ ] Если в хранилище попал мусор или старый формат — приложение не падает
- [ ] Данные не уходят на сервер (никаких запросов)

## Что НЕ входит

- Синхронизация между устройствами
- Аккаунты и сервер
