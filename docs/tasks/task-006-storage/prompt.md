# Промпт для Task-006

Сделай сохранение состояния в браузере для приложения «Миксер рецептов».

## Зачем

Приложение должно помнить своё состояние между запусками. Иначе при каждой
перезагрузке рецепты меняются, и один раз сходить в магазин по готовому
списку не получится.

## Где хранить

`localStorage` в браузере. Один ключ:

```js
const STORAGE_KEY = "mixer-state-v1";
```

Данные остаются только на устройстве пользователя, никуда не отправляются.

## Что хранить

```js
{
  version: 1,
  today: "2026-10-25",          // дата набора
  current: [3, 7, 12, 18, 21, 26],  // id рецептов на сегодня
  history: [                    // последние 7 дней, новые сверху
    { date: "2026-10-25", ids: [3, 7, 12, 18, 21, 26] }
  ],
  favorites: [],
  excluded: [],
  perCategory: 2,               // 2 или 3 рецепта в каждой категории
  checkedItems: ["onion", "eggs"],   // id купленных продуктов
  shoppingEnabled: [3, 7]       // id рецептов, отмеченных «Добавлю в покупки»
}
```

## Правила

1. При загрузке страницы — прочитать из `localStorage`, применить к `state`.
2. Сохранять при каждом изменении состояния, но не чаще раза в секунду
   (сделай простой «отложенный» вызов через `setTimeout`).
3. Если данных нет — пустое состояние, всё работает как в первый раз.
4. Если формат другой версии (например, нет поля `version` или оно не 1) —
   начать с чистого состояния, ничего не ломать.
5. Если `state.today` не совпадает с сегодняшней датой — набор должен обновиться
   сам (это уже есть в Task-004), но покупки, любимое и история остаются.

## Дополнительно

В подвале добавь ссылку «Сбросить всё»:

```html
<button type="button" id="reset-btn" class="link-btn">Сбросить всё</button>
```

По нажатию — спросить подтверждение (`confirm`), очистить `localStorage`,
перезагрузить страницу.

## Проверка

1. Нажал «Мешать» → перезагрузил страницу → набор тот же
2. Отметил «куплено» в списке покупок → перезагрузил → галочки на месте
3. Нажал «Сбросить всё» → подтвердил → всё чисто, приложение как в первый раз
4. Вручную положил в `localStorage` мусор (`{"version": "abc"}`) → страница
   открывается без ошибок
5. В консоли нет ошибок
