# Task-007 — Расширение каталога до 30 рецептов

## Задача

Нужно довести каталог с 15-20 рецептов до 30, чтобы на неделю не было повторов.

Считаем: 6 рецептов в день (2 завтрака + 2 обеда + 2 ужина). 30 рецептов —
это 5 дней без повторов. Для недели нужно минимум 42.

## Что входит в работу

1. Открыть `recipes.js`, посмотреть, что уже есть.
2. Дописать рецепты, чтобы всего стало **30 штук** (или больше, если добавишь
   про запас — не меньше 30).
3. Добавлять в первую очередь в те категории, где их меньше всего.
4. **Разобрать рецепты с `category: "перекус"`.** Сейчас их 6 штук, а меню
   у нас только 2+2+2 — без перекуса. Переведи подходящие из них в
   `завтрак` / `обед` / `ужин` (по времени готовки и продуктам), остальные
   оставь — пригодится, если добавим четвёртый слот.
5. Проверить каждый новый рецепт:
   - время готовки 20-30 минут
   - ингредиенты — обычные, из Ленты
   - формат — ровно как у существующих рецептов
6. Сверить все ингредиенты всех рецептов со справочником `ingredients.json`.
   Если какого-то продукта нет в справочнике — добавить его в справочник.

## Формат рецепта — строго как в Task-002

```js
{
  id: 21,                       // id продолжается с последнего, без повторов
  title: "Куриные наггетсы домашние",
  category: "ужин",            // завтрак | обед | ужин
  time: 25,
  servings: 2,
  ingredients: [
    { name: "Куриное филе", amount: "400", unit: "г" },
    { name: "Яйца куриные", amount: "1", unit: "шт" },
    { name: "Хлеб", amount: "100", unit: "г" }
  ],
  steps: [
    "Измельчите филе в блендере или через мясорубку.",
    "Добавьте яйцо, соль, перец и перемешайте.",
    "Слепите наггетсы и обваляйте в нарезанном хлебе.",
    "Обжарьте на сковороде по 3 минуты с каждой стороны."
  ]
}
```

**Внимание:** формат не менять. От него зависит остальной код.

## Как понять, что готово

- [ ] В `recipes.js` не меньше 30 рецептов
- [ ] id уникальны и идут подряд, без дырок и повторов
- [ ] У всех рецептов заполнены все поля
- [ ] Время готовки всех рецептов — от 20 до 30 минут
- [ ] Категории `завтрак` / `обед` / `ужин` — примерно по 10 каждая
- [ ] Все ингредиенты есть в `ingredients.json` (или добавлены в него)
- [ ] Файл открывается без ошибок, `RECIPES.length` показывает правильное число

## Что НЕ входит

- Новые поля в рецептах (калории, фото, рейтинг)
- Изменение формата
- Переписывание существующих рецептов
