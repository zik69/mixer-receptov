# Промпт для Task-007

Доведи каталог рецептов «Миксер рецептов» до 30 штук.

## Зачем

Меню на день — это 6 рецептов (2 завтрака + 2 обеда + 2 ужина).
При 30 рецептах получается 5 дней без повторов. Этого мало, но уже
работает. Сейчас в базе ~15-20 рецептов — нужно дотянуть.

## Что сделать

1. Открой `recipes.js`, посчитай сколько рецептов уже есть.
2. Допиши недостающие до **30 штук** (или больше).
3. Сначала добавляй в те категории, где рецептов меньше всего.
   В итоге должно быть примерно поровну: завтраки / обеды / ужины.
4. **Перевеси рецепты с `category: "перекус"`.** В готовом каталоге их 6 штук,
   а меню у нас 2 завтрака + 2 обеда + 2 ужина — перекус не выпадает никогда.
   Посмотри каждый: если по времени и продуктам он тянет на завтрак или обед —
   поменяй категорию. Если это явно перекус (сэндвич, бутерброд, салат-скор,
   творожная масса) — оставь как есть, пригодится потом.
5. Сверь все ингредиенты с `ingredients.json`. Чего нет в справочнике —
   добавь туда (в том же формате).

## Формат — НЕ МЕНЯТЬ

Копируй формат существующих рецептов. Новый рецепт добавляй в конец массива:

```js
{
  id: 21,
  title: "Куриные наггетсы домашние",
  category: "ужин",
  time: 25,
  servings: 2,
  ingredients: [
    { name: "Куриное филе", amount: "400", unit: "г" }
  ],
  steps: [
    "Шаг 1",
    "Шаг 2"
  ]
}
```

- `id` — продолжай с последнего существующего, без пропусков и повторов
- `category` — строго `завтрак`, `обед` или `ужин` (как в существующих)
- `time` — от 20 до 30
- `servings` — 2
- `ingredients` — массив `{ name, amount, unit }`, `name` — название продукта
  так, как оно есть в `ingredients.json` (в поле `name` или в `aliases`)
- `steps` — массив строк, 3-5 шагов, коротко и по делу

## Требования к рецептам

- Время готовки 20-30 минут (с учётом подготовки)
- Ингредиенты — обычные продукты из Ленты, без деликатесов
- Разнообразие: чтобы 30 рецептов не были 30 вариантами макарон
- Ужины — посытнее, завтраки — быстрые

## Примеры, если нужны вдохновения

**Завтраки:** омлет с сыром, сырники, блинчики с творогом, тост с яйцом и авокадо,
каша овсяная с бананом, омлет с беконом, яичница с овощами, творожная запеканка

**Обеды:** гречка с говядиной, салат с курицей, борщ, суп с макаронами,
рис с овощами и яйцом, тушёная капуста с мясом, макароны с курицей,
плов с курицей

**Ужины:** макароны с курицей и овощами, картофельное пюре с котлетой,
курица в духовке с картошкой, рыба с овощами, пельмени с бульоном,
плов, паста с болоньезом, салат с тунцом, овощное рагу

## Проверка

- `RECIPES.length` >= 30
- Все id уникальны
- Все `time` в диапазоне 20-30
- Категории примерно поровну
- В `ingredients.json` есть каждый продукт из всех рецептов
