# Task-009 — Исключаемые ингредиенты (аллергены и нелюбимые продукты)

## Задача

Пользователь хочет убирать нелюбимые продукты и аллергены из учёта, чтобы они не попадали в меню.

## Что входит в работу

1. Добавить в интерфейс способ исключать ингредиенты: поле ввода или список с чекбоксами.
2. Исключённые ингредиенты сохраняются в браузере (state.excluded).
3. «Мешать» не выдаёт рецепты, содержащие исключённые ингредиенты (логика isAllowed уже есть).
4. Показать список исключённых с возможностью удалить из него.
5. Учесть синонимы ингредиентов (через словарь ingredients.json).

## Как понять, что готово

- Можно добавить ингредиент в список исключённых, и он появляется в списке.
- После «Мешать» в меню нет рецептов с этим ингредиентом.
- Исключённый ингредиент можно убрать из списка, и он снова учитывается.
- Список сохраняется после перезагрузки страницы.
- Ничего из старого не сломалось: день и неделя, напоминания, ИИ-планер, импорт и экспорт, темы, блоки суток.

## Что не входит

- Автоматическое определение аллергенов по профилю пользователя.
- Рекомендации замен исключённых ингредиентов (это Task-013).

## Я, как пользователь

Я, как пользователь, хочу убирать нелюбимые продукты и аллергены, чтобы они не попадали в меню и список покупок.
