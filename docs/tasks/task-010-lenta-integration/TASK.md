# Task-010 — Интеграция с Лентой (цены и наличие)

## Задача

Пользователь хочет видеть, что есть в его Ленте и по какой цене, чтобы понимать, во сколько обойдётся ужин.

## Что входит в работу

1. Запрос к API Ленты (integration.api.lenta.com) для каждого ингредиента из списка покупок.
2. Магазин — Тверской гипермаркет (store_id 144).
3. Кнопка «Обновить цены» — отдельная, не при каждом «Мешать».
4. Для каждого ингредиента показываем список найденных товаров с ценами; пользователь выбирает нужный.
5. Выбранная цена сохраняется в state.lentaPrices и в localStorage.
6. При ошибке сети/товара — показываем «—», остальное не ломаем.

## Как понять, что готово

- Кнопка «Обновить цены» загружает варианты товаров для каждого ингредиента.
- Можно выбрать товар из выпадающего списка, цена отображается рядом.
- Выбор сохраняется после перезагрузки.
- Ничего из старого не сломалось.

## Что не входит

- Автоматический расчёт итоговой суммы корзины (отдельная задача).
- Выбор магазина пользователем (зашит Тверской гипермаркет).

## Я, как пользователь

Я, как пользователь, хочу видеть, что есть в моей Ленте и по какой цене, чтобы понимать, во сколько обойдётся ужин.
