# Task-020 — Выбор необычной кухни (китайская, 20 рецептов)

## Задача

Пользователь хочет иногда готовить необычные блюда — например, китайскую кухню.
Нужно добавить 20 рецептов китайской кухни и возможность выбрать «режим кухни»,
чтобы «Мешать» выдавал рецепты только из выбранной кухни.

## Что входит в работу

1. Добавить в `recipes.js` 20 новых рецептов китайской кухни (id 101-120).
   Категории: завтрак, обед, ужин — примерно по 6-7 в каждой.
   Время готовки: 20-30 минут.
   Ингредиенты — доступные в Ленте (соевый соус, кунжутное масло, имбирь,
   рисовая лапша, тофу, бамбук и т.п. — только то, что реально продаётся).
2. Добавить поле `cuisine` в каждый рецепт: `"обычная"` или `"китайская"`.
   У существующих 100 рецептов — `"обычная"`.
3. В интерфейсе — переключатель кухни: «Обычная» / «Китайская».
   При выборе «Китайская» кнопка «Мешать» берёт рецепты только из китайских.
4. Сверить все новые ингредиенты со словарём `ingredients.json` — добавить
   недостающие (соевый соус, кунжутное масло, имбирь, рисовая лапша, тофу и т.д.).
5. При переключении кухни сбрасывать историю (чтобы не было конфликтов).

## Как понять, что готово

- [x] В `recipes.js` 120 рецептов (100 обычных + 20 китайских)
- [x] У всех рецептов есть поле `cuisine`
- [x] Переключатель кухни работает: «Мешать» выдаёт рецепты только из выбранной
- [x] Все ингредиенты китайских рецептов есть в словаре
- [x] Файл открывается без ошибок

## Что НЕ входит

- Другие кухни (итальянская, мексиканская и т.д.) — отдельные задачи
- Изменение формата существующих рецептов (только добавление поля `cuisine`)
- Перевод интерфейса на китайский
- Интеграция с Лентой для китайских продуктов (Task-010)
