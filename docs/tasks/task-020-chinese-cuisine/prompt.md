# Промпт для Task-020

Добавь в приложение «Миксер рецептов» возможность готовить китайскую кухню.

## Зачем

Пользователь хочет иногда готовить необычные блюда — например, китайскую кухню.
Сейчас в каталоге только обычные рецепты. Нужно добавить 20 китайских рецептов
и возможность переключаться между кухнями.

## Что сделать

### 1. Добавить поле `cuisine` в рецепты

В каждый рецепт в `recipes.js` добавить поле:
- `cuisine: "обычная"` — для существующих 100 рецептов
- `cuisine: "китайская"` — для новых 20 рецептов

### 2. Добавить 20 китайских рецептов (id 101-120)

Категории: завтрак, обед, ужин — примерно по 6-7 в каждой.
Время готовки: 20-30 минут.
Ингредиенты — доступные в Ленте: соевый соус, кунжутное масло, имбирь,
рисовая лапша, тофу, бамбук, крахмал, рисовый уксус и т.п.

Примеры блюд:
- Курица в кунжутном масле с овощами
- Рисовая лапша с курицей и овощами
- Тофу с овощами в соевом соусе
- Суп с рисовой лапшой и курицей
- Жареный рис с яйцом и овощами
- Курица в кисло-сладком соусе
- Салат из огурцов с чесноком и соевым соусом

### 3. Переключатель кухни в интерфейсе

Добавить в `index.html` переключатель:
```html
<div class="cuisine-switch">
  <button data-cuisine="обычная" class="active">Обычная</button>
  <button data-cuisine="китайская">Китайская</button>
</div>
```

При выборе «Китайская» кнопка «Мешать» берёт рецепты только из китайских.
При переключении — сбросить историю и перегенерировать набор.

### 4. Обновить словарь ингредиентов

Добавить в `ingredients.json` новые продукты:
- Соевый соус
- Кунжутное масло
- Имбирь свежий
- Рисовая лапша
- Тофу
- Бамбук консервированный
- Крахмал кукурузный
- Рисовый уксус
- Кунжут
- Устричный соус

## Формат рецепта

```js
{
  id: 101,
  title: "Курица в кунжутном масле с овощами",
  category: "ужин",
  cuisine: "китайская",
  time: 25,
  servings: 2,
  ingredients: [
    { name: "Куриное филе", amount: "300", unit: "г" },
    { name: "Соевый соус", amount: "2", unit: "ст.л." },
    { name: "Кунжутное масло", amount: "1", unit: "ст.л." }
  ],
  steps: ["Шаг 1", "Шаг 2"]
}
```

## Проверка

- `RECIPES.length` >= 120
- Все id уникальны (1-120)
- Все `time` в диапазоне 20-30
- Переключатель кухни работает
- Все ингредиенты китайских рецептов есть в словаре
- В консоли нет ошибок
