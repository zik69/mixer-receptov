# Task-021 — Просмотр всех карточек рецептов

## Задача

Пользователь хочет иметь возможность посмотреть все рецепты каталога,
а не только случайные 6 на день. Нужно добавить страницу/раздел «Все рецепты»,
где можно листать карточки и искать по названию.

## Что входит в работу

1. Добавить в `index.html` кнопку/ссылку «Все рецепты» (в шапке или подвале).
2. При нажатии — показать все карточки рецептов (100+ штук) в виде сетки.
   Каждая карточка — как на главной: категория, время, порции, ингредиенты,
   кнопка «Показать рецепт», чекбокс «Добавлю в покупки».
3. Поиск по названию: поле ввода, фильтрует карточки по введённому тексту
   (регистронезависимо).
4. Фильтр по категории: кнопки «Все» / «Завтраки» / «Обеды» / «Ужины».
5. Кнопка «Назад» / «Закрыть» — возвращает на главную страницу с меню на день.
6. При открытии «Все рецепты» набор на сегодня не меняется (не трогаем state).

## Как понять, что готово

- [x] Кнопка «Все рецепты» открывает список всех карточек
- [x] Видны все 100+ рецептов
- [x] Поиск по названию работает
- [x] Фильтр по категории работает
- [x] Кнопка «Назад» возвращает на главную
- [x] При возврате набор на день не изменился
- [x] В консоли нет ошибок

## Что НЕ входит

- Сортировка по времени/популярности (отдельная задача)
- Редактирование рецептов (отдельная задача)
- Добавление своих рецептов (Task-017)
- Пагинация (показываем все сразу, сетка)
