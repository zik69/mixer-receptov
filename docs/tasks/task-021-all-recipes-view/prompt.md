# Промпт для Task-021

Сделай возможность посмотреть все карточки рецептов в приложении «Миксер рецептов».

## Зачем

Сейчас пользователь видит только 6 случайных рецептов на день. Хочется иметь
возможность посмотреть весь каталог — листать карточки, искать по названию,
фильтровать по категории.

## Что сделать

### 1. Кнопка «Все рецепты»

Добавить в `index.html` (в шапку или рядом с кнопкой «Мешать»):
```html
<button type="button" id="all-recipes-btn" class="link-btn">Все рецепты</button>
```

### 2. Экран «Все рецепты»

При нажатии — показать отдельный экран (можно в виде модального окна или
отдельной секции, которая скрывает основной контент):
- Заголовок «Все рецепты»
- Кнопка «Назад» / «Закрыть»
- Поле поиска: `<input type="search" id="recipe-search" placeholder="Поиск по названию">`
- Кнопки фильтра: «Все» / «Завтраки» / «Обеды» / «Ужины»
- Сетка карточек (все рецепты из `RECIPES`)

### 3. Отрисовка карточек

Использовать существующую функцию `renderCard(recipe)` — та же карточка,
что и на главной. Чекбокс «Добавлю в покупки» тоже работает.

### 4. Поиск

При вводе текста в поле поиска — фильтровать карточки по названию
(регистронезависимо). Показывать только те, чьё название содержит введённый текст.

### 5. Фильтр по категории

Кнопки переключают фильтр:
- «Все» — показать все
- «Завтраки» — только `category: "завтрак"`
- «Обеды» — только `category: "обед"`
- «Ужины» — только `category: "ужин"`

Активная кнопка подсвечена.

### 6. Возврат на главную

Кнопка «Назад» / «Закрыть» скрывает экран «Все рецепты» и показывает
основной контент. Набор на день не меняется.

## Проверка

- Кнопка «Все рецепты» открывает список
- Видны все 100+ рецептов
- Поиск по названию работает
- Фильтр по категории работает
- Кнопка «Назад» возвращает на главную
- При возврате набор на день не изменился
- В консоли нет ошибок
