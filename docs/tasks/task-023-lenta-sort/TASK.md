# Task-023 — Сортировка товаров Ленты по цене

## Задача

Пользователь хочет быстро выбрать самые дешёвые или дорогие товары Ленты для списка покупок.

## Что входит в работу

1. Кнопки «Дешёвые», «Дорогие», «По скидке» рядом с заголовком списка покупок.
2. При нажатии — для каждого ингредиента с вариантами Ленты выбирается товар с min/max ценой или max скидкой.
3. Выбор сохраняется в state.lentaPrices.
4. Рейтинг товаров не поддерживается API Ленты — вместо него сортировка по скидке.

## Как понять, что готово

- Кнопки меняют выбор товаров во всех строках.
- Общая сумма пересчитывается.
- Ничего из старого не сломалось.

## Я, как пользователь

Я, как пользователь, хочу быстро выбирать самые дешёвые или дорогие товары Ленты для списка покупок.
