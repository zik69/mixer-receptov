Добавить кнопки сортировки товаров Ленты: «Дешёвые», «Дорогие», «По скидке».

Требования:
- Кнопки рядом с заголовком списка покупок (на главной и в «Все рецепты»).

- Рейтинг не поддерживается API — заменён на скидку.
