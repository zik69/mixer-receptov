# Task-024 — Рефакторинг кода

## Задача

Я, как разработчик, хочу разложить код по понятным файлам и убрать повторы,
чтобы новые задачи делались быстрее и чтобы в коде не заводились ошибки
из-за копирования одного и того же в разные места.

## Что не так сейчас

Вся логика лежит в одном файле `app.js` — 1289 строк. В нём сразу:
состояние, сохранение в браузере, выбор рецептов, карточки, список покупок,
цены Ленты, экран «Все рецепты» и кнопки. Найти нужное место трудно.

Кроме того, одни и те же куски повторяются:

- проверка «есть ли справочник продуктов» — 8 раз;
- поиск продукта по названию и синонимам — 3 раза;
- подсчёт «сколько пакетов брать» — 2 раза (в списке и в итоговой сумме);
- перечисление кнопок Ленты — 2 раза по 4 id подряд.

## Что входит в работу

1. Разбить `app.js` на файлы в папке `js/`:

   | Файл | Что внутри |
   |---|---|
   | `basics.js` | настройки, состояние, мелкие помощники, сохранение в браузере |
   | `menu.js` | каталог рецептов и выбор 2+2+2, кухни, исключённые продукты |
   | `card.js` | карточка рецепта и главный экран |
   | `shopping.js` | сведение продуктов, единицы, пакеты, список покупок |
   | `lenta.js` | цены и сортировки Ленты |
   | `all-recipes.js` | экран «Все рецепты» и «что есть дома» |
   | `main.js` | запуск приложения и кнопки |

2. Убрать повторы: сделать одну функцию «есть ли справочник», одну функцию
   поиска продукта, одну функцию «сколько пакетов брать», один список кнопок
   Ленты.

3. Убрать устаревшие комментарии вроде «28 рецептов» (в каталоге давно больше).

4. Раздел «Выбранное» на главной перенести из кода в `index.html` — чтобы
   страница целиком описывалась разметкой, а не собиралась на ходу.

## Что сделано

- `app.js` разложен на семь файлов в `js/`; `index.html` подключает их по порядку.
- Убраны повторы: `ingredientsDb()`, `findIngredient()`/`canonicalName()`, `packsFor()`, `lentaActionButtons()`, `bindClick()`, `recipesById()`.
- Раздел «Выбранное» перенесён в `index.html`.
- Попутно исправлена горизонтальная прокрутка на 390 px: кнопки Ленты в шапке списка покупок теперь переносятся на новую строку.
- Скриншоты: `mockups/mobile.png`, `mockups/desktop.png`.

## Что в эту задачу не входит

- Новые функции и новые рецепты.
- Изменение внешнего вида — он должен остаться прежним.
- Переход на сборщики, модули и сторонние библиотеки: страница по-прежнему
  открывается двойным щелчком по `index.html`, работает без сети.
- Правка данных: `recipes.js`, `ingredients.js`, `styles.css` не трогаем.
