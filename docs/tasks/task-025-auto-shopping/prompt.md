# Промпт для Task-025

Сделай так, чтобы список покупок собирался сам из меню на день.

## Что сделать

1. После `generateMenu()` все рецепты дня считаются «в списке покупок»:
   `state.checked` заполняется id рецептов дня.
2. `renderShoppingList` берёт продукты из `state.checked` — как сейчас,
   отдельная ветка не нужна.
3. На главной отмеченная карточка **не переезжает** в «Выбранное»:
   `render()` больше не создаёт и не заполняет этот блок, карточка
   остаётся на месте с пометкой «В списке».
4. На экране «Все рецепты» блок «Выбранное» остаётся как есть.
5. При новом наборе (`generateMenu`) `state.bought` очищается.
6. «Снять отметки» очищает только `state.bought`.

## Проверить

- сразу после «Мешать» в списке продукты всех 6 рецептов;
- снял галочку — продукты ушли из списка;
- на главной нет «Нет подходящих рецептов», если рецепты дня есть;
- на «Все рецепты» отмеченные собираются в «Выбранное»;
- после перезагрузки всё сохраняется;
- 390 px без прокрутки вбок, консоль чистая.
