# Task-026 — Количества на 2 человек

## Задача

Я, как пользователь, хочу видеть в карточке рецепта количества продуктов
сразу на 2 человек, чтобы не пересчитывать в голове и чтобы карточка
не спорила со списком покупок.

## В чём проблема сейчас

В каталоге 81 рецепт из 150 рассчитан на 3–6 порций. Карточка показывает
исходные количества и подпись «4 порции», а список покупок те же продукты
считает на 2 человек — то есть вдвое меньше. Два разных числа на один
и тот же продукт.

## Что входит в работу

- На карточке показывать количество, пересчитанное на 2 человек.
- Подпись в карточке: «N мин · на 2 человек» вместо «N порций».
- Пересчёт делать в момент показа, данные рецептов не менять.
- Нечисловые количества («по вкусу», «щепотка») оставлять как есть.
- Шаги приготовления не трогать: числа в них — это минуты, а не граммы.

## Как понять, что готово

- [x] Карточка рецепта на 4 порции показывает половину количеств
- [x] Карточка рецепта на 2 порции показывает те же числа, что и раньше
- [x] «По вкусу» и «щепотка» остаются без изменений
- [x] Числа на карточке совпадают со списком покупок для этого рецепта
      (список округляет до целых — так удобнее покупать)
- [x] Дробные количества выглядят по-русски: «0,5 шт», а не «0.5 шт»
- [x] На телефоне (390 px) ничего не поехало
- [x] В консоли браузера нет ошибок

## Что не входит

- Правка файла рецептов (там остаются исходные порции).
- Настройка «на сколько человек готовим» — по-прежнему всегда 2.
- Изменение шагов приготовления.
