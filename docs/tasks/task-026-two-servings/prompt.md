# Промпт для Task-026

Покажи в карточке рецепта количества на 2 человек, не меняя файл рецептов.

## Что сделать

1. В `js/basics.js` — помощники `formatQty`, `roundForCooking`, `amountForServings`.
2. В `js/card.js` — `ingredientsForCard(recipe)` пересчитывает каждый ингредиент
   на `TARGET_SERVINGS` (2) и возвращает `{ name, unit, amount }`.
3. Подпись в карточке: `«N мин · на 2 человек»` вместо `«N порций»`.

## Правила округления

- граммы и миллилитры — до целых;
- штуки, ложки, зубчики, ломтики, пучки — до половины, минимум 0,5;
- килограммы и литры — до сотых;
- «по вкусу», «щепотка» — не трогать;
- дробные числа писать через запятую.

## Проверить

- рецепт на 4 порции показывает половину количеств;
- рецепт на 2 порции не изменился;
- шаги не тронуты;
- 390 px без прокрутки вбок, консоль чистая.
