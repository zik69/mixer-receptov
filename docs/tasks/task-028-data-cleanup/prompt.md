# Промпт для Task-028

Почини данные каталога: убери категорию «перекус» и добавь китайские завтраки.

## Что сделать

1. В `recipes.js` перенести четыре рецепта с `category: "перекус"`:
   - «Салат из свежих овощей» → `ужин`;
   - «Фруктовый салат с йогуртом» → `завтрак`;
   - «Брускетта с помидорами» → `завтрак`;
   - «Салат из огурцов с чесноком» → `обед`.
2. Добавить три китайских завтрака (id 151–153) на 20–30 минут:
   рисовая каша с яйцом, омлет с помидорами, блинчики с зелёным луком.
3. Использовать только те продукты, которые уже есть в `ingredients.js`.

## Проверить

- в каталоге нет `category: "перекус"`;
- китайская кухня выдаёт 6 карточек, в режиме «3» — 9;
- новые продукты находятся в справочнике;
- список покупок по новым рецептам собирается без «Не найдено».
