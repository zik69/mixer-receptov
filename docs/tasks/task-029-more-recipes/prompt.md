# Промпт для Task-029

Добавь в каталог 50 новых рецептов: 20 обычных, 15 китайских, 15 сложных.

## Правила

- Файл один: `recipes.js`. Новые рецепты — в конец массива, id 154–203.
- Формат как у существующих: `{ id, title, category, cuisine, time, servings, ingredients[], steps[] }`.
- `category` — только `завтрак`, `обед`, `ужин`.
- `cuisine` — `обычная`, `китайская`, `сложная`.
- Время: 20–30 минут, у сложных до 45.
- Продукты — только те, что уже есть в `ingredients.js` (проверять через поиск по имени и синонимам).
- Названия не должны повторяться с уже существующими.
- Шаги — 4–6 коротких предложений, как в остальном каталоге.

## Распределение

| Кухня | Завтрак | Обед | Ужин |
|---|---|---|---|
| обычная | 6 | 7 | 7 |
| китайская | 5 | 5 | 5 |
| сложная | 5 | 5 | 5 |

## Проверить

- в каталоге 203 рецепта, id без повторов;
- названия уникальны;
- ни один продукт не остаётся «не найдено» в списке покупок;
- меню по «Мешать» даёт по 6 карточек в каждой кухне и 9 в режиме «3»;
- 390 px без прокрутки вбок, консоль чистая.
