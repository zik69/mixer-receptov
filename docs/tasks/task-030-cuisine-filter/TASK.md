# Task-030 — Фильтр по кухне в «Всех рецептах»

## Задача

Я, как пользователь, хочу на экране «Все рецепты» отбирать блюда по кухне,
чтобы быстро смотреть только китайские, только сложные или только обычные.

## В чём проблема сейчас

На главной есть переключатель кухни, а на экране «Все рецепты» — только
поиск и категории (завтраки/обеды/ужины). Чтобы найти китайское блюдо,
приходится листать 203 карточки или искать по названию.

## Что входит в работу

- Второй ряд кнопок под категориями: «Все кухни», «Обычная», «Китайская»,
  «Сложная».
- Фильтр работает вместе с поиском, категорией и «Что есть дома».
- При открытии экрана фильтр сбрасывается на «Все кухни», как и категория.
- Внешний вид — как у соседних кнопок, без новых стилей.

## Как понять, что готово

- [x] На экране «Все рецепты» есть второй ряд кнопок с кухнями
- [x] «Обычная» показывает 120 рецептов, «Китайская» — 38, «Сложная» — 45
- [x] «Китайская» + «Завтраки» дают 9 рецептов
- [x] Поиск работает внутри выбранной кухни
- [x] При повторном открытии экрана снова выбрано «Все кухни»
- [x] Нажатие на кухню не переключает кухню на главной странице
- [x] На телефоне (390 px) кнопки переносятся, прокрутки вбок нет
- [x] В консоли браузера нет ошибок

## Что сделано

- Над вторым рядом кнопок — фильтр по кухне.
- `renderAllRecipes` учитывает кухню вместе с категорией, поиском и «Что есть дома».
- При открытии экрана обе группы фильтров сбрасываются на «Все».
- Столбец «Кухня» на главной не затрагивается: кнопки на экране «Все рецепты»
  переключают только свой фильтр.

## Что не входит

- Изменение правил выбора меню.
- Запоминание фильтра между открытиями.

## Заметка про кэш

Ко всем подключаемым файлам в `index.html` теперь стоит номер версии.
Когда меняются код или данные — номер нужно поднять (например, на `20261101`),
иначе браузер может показывать старую копию до 10 минут.
