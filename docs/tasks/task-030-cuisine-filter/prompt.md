# Промпт для Task-030

Добавь на экран «Все рецепты» фильтр по кухне.

## Что сделать

1. В `index.html` под рядом категорий добавить второй ряд кнопок с той же
   разметкой `.all-recipes-screen__cat`, но с атрибутом `data-cuisine`:
   `all`, `обычная`, `китайская`, `сложная`.
2. В `js/all-recipes.js`:
   - переменная `allRecipesCuisine` (по умолчанию `"all"`);
   - в `renderAllRecipes` добавить проверку кухни в общий фильтр;
   - в `initAllRecipesScreen` разделить выборки: категории — `[data-cat]`,
     кухни — `[data-cuisine]`; при открытии сбрасывать обе на `all`;
   - обработчик нажатия переключает `allRecipesCuisine` и активную кнопку.
3. Стили не трогать: кнопки используют существующий класс.

## Проверить

- 203 рецепта всего; по кухням 120 / 38 / 45;
- «Китайская» + «Завтраки» = 9;
- поиск работает внутри кухни;
- переключение на экране не меняет кухню на главной;
- 390 px без прокрутки вбок, консоль чистая.
